# 🔐 Book-Shelf: 1 — Penetration Testing

> Authorized penetration testing assessment of the **Book-Shelf: 1** VulnHub training machine in an isolated VMware lab environment.

---

## 📌 Project Overview

This project documents a complete penetration testing assessment performed against the **Book-Shelf: 1** vulnerable virtual machine.

The assessment focused on identifying, validating, and documenting security weaknesses across the target's:

- Network services
- Web application
- Authentication mechanisms
- File permissions
- Access controls
- Command execution
- Privilege escalation opportunities

The engagement was conducted in an **authorized and isolated lab environment** for educational and cybersecurity training purposes.

---

## 🎯 Objectives

The main objectives of the assessment were to:

- Perform network reconnaissance and host discovery
- Identify exposed ports and services
- Enumerate the web application
- Identify information disclosure vulnerabilities
- Assess authentication and authorization controls
- Identify and validate injection vulnerabilities
- Obtain initial access where possible
- Perform post-exploitation enumeration
- Assess potential privilege escalation paths
- Document findings and provide remediation recommendations
